# IC Copilot → Weekly Alpha research transfer (offline producer pilot)

**Status 2026-11-14:** additive draft. No live forecast or user private data exported, no production connection, GitHub dispatch, cloud job, API calls, credential, model invocation or schedule change. Keep this branch independent of ongoing IC Copilot forecasting/Codex development.

- `scripts/export_weekly_alpha_candidate.py` accepts **already validated**, user-authored prospective binary forecast JSON, explicit source URL/hash, first published/observed, model version, baseline probability and time, question, expiry and falsifier, and writes an *allowlisted* JSON envelope **outside** this public repository only. No authorization token, CLI network, print of forecast content, or overwrite of existing output.
- `tests/test_weekly_alpha_forecast_export.py` synthetic only checks no future baseline, no invented source receipt, no secret field, version lineage and bounded probabilities.
- Consumer (private) Weekly Alpha research [PR59](https://github.com/mwsp-code/weekly-market-research-data/pull/59) contains `src/ic_forecast_dispatch_stager.py` and an **unmerged** GitHub `repository_dispatch` / manual workflow with quarantined receipt. Since GitHub dispatch requires workflow on default branch, neither automatic trigger nor producer credential exists as of this draft.
- When the IC forecasting/QA code actually produces a **new qualified forecast**, call this exporter with the app's authoritative `model_version`, `source_vintage_id` and cutoff from its registered finalization event, not a later narrative or revised history. Save candidate outside repo; independently inspect the SHA, rights, forecast question and real maturity date. Only then enable the producer's targeted GitHub workflow dispatch with a fine-grained token/App installation permitted to emit events to the private destination; never place this credential in manifests or the public frontend.
- GitHub event receipt and run records anchor future observations; the process should validate arrival before outcome and preserve the original record via reviewed immutable private commit, then keep revisions as explicit linked successors. CI status and source hashes alone do not prove genuine preregistration; the *receiver review* must validate server-side event clocks and original issuer statements. Webcast/third-party transcripts cannot be exported as unrestricted raw content.
- Phase-in: (1) offline synthetic/one current demonstration with no real prediction; (2) a real future source-qualified forecast with documented source/time and benchmark; (3) compare downstream rating/contract/model outputs; (4) only after limits, rights, CI and rollback are verified can a controlled dispatcher connect the two apps.
- Portfolio holdings and private research must remain in the **private** Weekly Alpha repo. IC Copilot is publicly visible. No direct dependency on Tuesday scheduled report; arriving forecast creates an independent research-queue candidate.
